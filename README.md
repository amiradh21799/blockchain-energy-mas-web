# ⚡ Blockchain-Integrated Multi-Agent Energy Management System

This project implements a decentralized energy management system that combines a multi-agent architecture with blockchain. A Streamlit-based web interface allows real-time interaction, simulation, and visualization of performance metrics.

## Features
- Multi-agent energy simulation (Buildings, EVs, Storage, PV, Grid)
- Blockchain integration (Ethereum via Ganache)
- Smart contract deployment and monitoring
- Real-time metrics: cost, comfort, equity, transaction analytics
- Visualizations: Sankey, Pie, Bar, Radar, Heatmap

## How to Run
1. Start Ganache
2. Run the Streamlit app:
```bash
streamlit run app.py
